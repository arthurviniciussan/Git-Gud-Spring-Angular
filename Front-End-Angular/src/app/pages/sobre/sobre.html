Sobre o GitGud

Um blog de opinião sobre jogos, escrito por uma pessoa só.

Sou o Arthur, desenvolvedor, e escrevo aqui sobre os jogos que jogo — sem calendário de lançamento para cumprir e sem nota inflada para agradar ninguém.

Cada texto é uma opinião, não um veredito. Quando dou uma nota, ela vale para a minha experiência com aquele jogo, naquele momento. Se você discordar, ótimo: é mais ou menos esse o ponto.

O site também é meu projeto de portfólio. O código está aberto no GitHub — backend em Spring Boot, frontend em Angular.
